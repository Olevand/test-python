# PythonProject
# Математический тест с использованием фикстуры pytest
Проект содержит практическую работу по написанию параметризованной фикстуры и тестов для функции сложения произвольного количества чисел.

## Требования
Для запуска тестов у вас должен быть установлен Python и пакет `pytest`.
1. **Запуск всех тестов в проекте:**
   ```bash
   pytest

2. **Запуск конкретного тестового файла с подробным выводом (рекомендуется для просмотра названий кейсов из ids):

```Bash
pytest math_test/tests/test_calculator.py -v
